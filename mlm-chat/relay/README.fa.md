# رلهٔ صندوق گوگل (`Mailbox.gs`)

یک Apps Script کوچک که در حساب گوگل خودِ کاربر می‌نشیند و پیام‌های **مهرشدهٔ** گره را تا چند ساعت نگه می‌دارد (بند ۱۹ `docs/SPEC.md`). اپ آن را با دو کلید تازه می‌سازد و مرحله‌به‌مرحله نشان می‌دهد؛ این فایل برای کسی است که می‌خواهد بداند داخلش چیست یا دستی بسازد.

## ساختن دستی

1. در اپ: «داده و حافظه» ← «رله‌های گوگل» ← «ساختن رلهٔ خودم». اسکریپت با کلیدها کپی می‌شود. (فایل `Mailbox.gs` در همین پوشه الگوی بی‌کلید است؛ نسخهٔ بی‌کلید هیچ‌وقت جز صفحهٔ فریب چیزی نمی‌دهد.)
2. script.google.com ← New project ← کد پیش‌فرض را پاک کن ← بچسبان ← Save.
3. Deploy ← New deployment ← Select type: Web app ← Execute as: **Me** ← Who has access: **Anyone** ← Deploy (اگر گوگل اجازه خواست، Allow).
4. «Deployment ID» (یا کل «Web app URL») را در اپ بچسبان. اپ خودش آزمایش می‌کند.

## چه چیزی در آن هست

- `put`/`take`/`chk`: گذاشتن، برداشتن (با انتظار تا ۲۰ ثانیه) و پرسیدن «هنوز هست؟»
- حافظه: `CacheService` (حداکثر ۶ ساعت، بهترین‌تلاش) و `PropertiesService` فقط برای تنظیم و جمع روزانه. **`UrlFetchApp` ندارد**: سهمیهٔ ۲۰ هزار فراخوانی بیرونی مصرف نمی‌شود، و اسکریپت هیچ جا تماس نمی‌گیرد.
- هیچ سرویس گوگلی که نیاز به دسترسی به ایمیل، فایل یا مخاطبان داشته باشد استفاده نشده.
- دو کلید: `USE_KEY` (در کارت مخاطبان می‌رود؛ هر کس دارد می‌تواند بگذارد و بردارد) و `OWNER_KEY` (فقط روی گوشی مالک؛ آمار، توقف، سقف دستگاه).
- کلید غلط، `GET` یا بدنهٔ خراب: صفحهٔ فریب (`The script completed but did not return anything.`).
- سقف پیش‌فرض ۴۰ دستگاه در روز؛ مالک در اپ عوض می‌کند.

## آزمون

```bash
node tools/mailbox-sim/test.mjs
```

خود فایل را با `CacheService`/`LockService`/`PropertiesService` ساختگی اما با همان سقف‌های گوگل اجرا می‌کند (۱۶ آزمون).

## رلهٔ Nostr داخل ایران (`nostr/setup-strfry.sh`، ت۵۴)

- روی سرور Ubuntu 24.04 (یا 22.04)، با کاربر root: `bash setup-strfry.sh <IP عمومی سرور>`. `strfry` را می‌سازد و پشت nginx روی پورت ۴۴۳ با گواهی خودامضا بالا می‌آورد. اجرای دوباره امن است و گواهی را عوض نمی‌کند.
- فقط قاب‌های گره پذیرفته می‌شود: `kind 1059` با برچسب `p` و انقضای حداکثر ۳ روز. هیچ لاگی نوشته نمی‌شود. سقف هر IP بالاست، چون اپراتورها گوشی‌های زیادی را پشت یک IP می‌گذارند.
- `strfry` تازه خواندن `kind 1059` را به‌طور پیش‌فرض فقط با ورود (NIP-42) باز می‌گذارد؛ گیرندهٔ گره وارد نمی‌شود، پس اسکریپت این قفل را برمی‌دارد و آخر کار همین را می‌آزماید.
- آخرش نشانی رله و اثر انگشت SHA-256 گواهی را چاپ می‌کند. این دو در `core/src/transport/nostr/mod.rs` (`RELAYS` و `PINNED`) می‌روند؛ اگر گواهی عوض شود، اپ باید به‌روز شود.
- اگر پنل سرور فایروال دارد، پورت ۴۴۳ TCP باید باز باشد. سرورهای داخلی گاهی SSH از IP خارجی را نمی‌پذیرند؛ بی VPN وصل شوید.
