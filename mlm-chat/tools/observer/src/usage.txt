mlm-observer: ناظر فاز ۰ MLM CHAT (راهنمای کامل: README.fa.md)

  --addr IP          نشانی‌ای که گوشی‌ها باید به آن وصل شوند (چند بار مجاز). اول نشانی عمومی مودم.
  --port N           درگاه اصلی TCP و UDP (پیش‌فرض 40100)
  --alt N            درگاه دوم TCP و UDP (پیش‌فرض درگاه اصلی + ۱)
  --extra-tcp A,B    درگاه‌های TCP بیشتر برای سنجش دسترسی، مثلاً 443,8443
  --bind IP          فقط روی این نشانی گوش بده (پیش‌فرض: همهٔ نشانی‌ها، IPv4 و IPv6)
  --name NAME        نام کوتاه ناظر در کارت و گزارش، مثلاً ehsan-home
  --key FILE         پروندهٔ کلید (پیش‌فرض observer-key.json)
  --upnp             از مودم بخواه درگاه‌ها را باز کند و نشانی بیرونی را بگوید
  --verbose          هر درخواست را در لاگ بنویس (بدون نشانی IP)
  --card-only        فقط کارت را نشان بده و بیرون برو
  --p2p-port N       درگاه TCP و UDP رلهٔ آزمایش libp2p (پیش‌فرض 40200)
  --iroh-port N      پایهٔ درگاه‌های آزمایش iroh (پیش‌فرض 40300): TCP N+1، UDP N+2 و N+3
  --no-spike         رله‌های آزمایش libp2p و iroh را روشن نکن
